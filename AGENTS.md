# TermPilot AI

Independent CISC3014 university timetable planning project. Read docs/PROJECT.md
for recovered context and unresolved decisions; docs/DEVELOPMENT.md for workflow.
The folder was empty when this setup was prepared on 2026-11-06. No framework,
package manager, backend, database, provider, or dependency version is established.
Inspect current files before choosing tools or architecture. shadcn/ui and CopilotKit
are user-selected integrations, not evidence of installed packages.

## Course boundaries
- Record tool/model, version when available, purpose, important prompts or generation
  steps, human verification and contributions in docs/AI-USAGE.md.
- Students must understand and verify every submitted line, result, citation and claim.
- Never upload personal data, restricted datasets, unpublished course solutions or
  unauthorized materials to external services. Use synthetic profiles for development.
- Course agents require limited tools and explicit step limits. They may not
  autonomously send messages, make purchases, delete data or modify real accounts.

## Working conventions
- Plan substantive changes, implement a small slice, verify it and explain the evidence.
- Use existing manifests and lockfiles once present; never guess runnable commands.
- Keep secrets server-side and outside Git. Do not read secret values into agent output.
- Preserve synced course references; do not copy them into this repo without authorization.
- Skill packs provide methods, not authority to bypass course policy or permissions.
- Superpowers leads engineering; Impeccable leads UI design; Anti-Slop is an optional
  focused review. Reuse one agreed brief rather than restarting discovery in every pack.
- Do not claim a skill, package or MCP server is installed/connected without checking.
- No automatic deployments, submissions, account operations or destructive cleanup.
